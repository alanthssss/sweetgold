# Maintenance mode

SweetGold paused new feature development after the first M15 auditable-agent
workflow reached `main`. The current scope is a complete, reproducible
multi-agent experimentation platform with a promoted cross-distribution policy.

Accepted maintenance work:

- critical defects and security fixes;
- broken installation, model download or CI workflows;
- reproducibility and documentation corrections;
- narrowly scoped compatibility updates.

Deferred work:

- new policy architectures and training curricula;
- Strategy Arena product expansion;
- multi-scenario agent recommendation policies.

Feature development can resume when there is a concrete research question,
predeclared evaluation protocol and time budget for untouched final seeds.
