# SweetGold v1.1.0

[English](v1.1.0.md) | [简体中文](v1.1.0.zh-CN.md)

v1.1.0 把初始研究平台扩展为可复现的策略比较与模型分发工作流。

## 亮点

- 可下载、带完整性校验和模型卡的晋级检查点。
- 双语模型注册卡片和一键本地安装。
- 排名透明的配对种子多策略联赛。
- 浏览器、脚本、CI 和 AI 智能体都能读取的持久 JSON 评测产物。
- M14 分层返航控制：首个通过完整跨分布鲁棒性门槛的策略。

## M14 结果

监督器使用安全余量 6、充能比例 0.8。在六种场景各 50 个未使用最终种子上，所有场景
均达到 100% 蜜蜂存活和 0% 无效动作；蜂蜜中位数为 Assignment 的 148.47%，最差
稀缺花蜜场景为 101.16%。

## 模型目录

[`models-v2`](https://github.com/alanthssss/sweetgold/releases/tag/models-v2)
包含所有晋级模型名、Apache-2.0 和机器可读清单。M14 与 M8 共享神经权重，新行为来自
有版本的监督器代码和注册参数。

## 升级与验证

```bash
python main.py --version
python main.py models download
python main.py models verify
python -m unittest discover -s tests -v
```

升级不会移除任何模型 ID 或命令；评测产物 API 和 `arena-league` 命令均为增量功能。
