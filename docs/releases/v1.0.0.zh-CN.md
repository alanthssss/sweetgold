# SweetGold v1.0.0

[English](v1.0.0.md) | [简体中文](v1.0.0.zh-CN.md)

v1.0.0 是可复现、可交互的多智能体 AI 实验平台，连接确定性模拟、规则基线、模仿学习、
强化学习、模型晋级、失败审计和并排比较产品。

## 亮点

- 相同初始世界和随机种子上的双策略比较与逐帧回放。
- 配置驱动的 BC、PPO、CTDE 流水线。
- 实验前拒绝种子泄漏。
- 只有置信度、产量和安全门槛都通过才晋级。
- 失败鲁棒性结果保存在结构化审计注册表。
- 模拟器和规则基线没有第三方依赖。

## 启动 Strategy Arena

```bash
python3 main.py play --port 8080
```

打开 <http://127.0.0.1:8080>。启用本地生成的学习策略：

```bash
python3 -m venv .venv-ml
.venv-ml/bin/pip install -r requirements-ml.txt
.venv-ml/bin/python main.py pipeline-m8 \
  --config experiments/m8-coordination.json
```

Arena 加载前会校验注册检查点摘要。

## v1.0 声明的内容

SweetGold 证明端到端多智能体实验工作流和科学诚实的晋级流程可以运行。通过的 M8 模型
相对局部行为克隆基线有所改善，同时消除了资源争用造成的无效动作。

## v1.0 不声明的内容

学习策略并非普遍鲁棒智能体。M10、M11 在恶劣天气和低能量下发现严重存活下降；候选被
拒绝，结果保存在 `registry/audits.json`，其最终种子不得用于调参。

内置服务器面向本地实验和演示，不提供认证、多用户隔离或生产服务保证。

## 验证

```bash
python3 main.py --version
python3 -m unittest discover -s tests -v
python3 main.py benchmark --episodes 30 --controllers greedy assignment
```

GitHub Actions 会运行可选 ML 冒烟流水线。
