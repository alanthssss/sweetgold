# SweetGold v1.0.0

[English](v1.0.0.md) | [简体中文](v1.0.0.zh-CN.md)

v1.0.0 是可复现、可交互的多智能体 AI 实验平台，连接确定性模拟、规则基线、模仿学习、
强化学习、模型晋级、失败审计和并排比较产品。

## 亮点

- 相同初始世界和随机种子上的双策略比较与逐帧回放。
- 配置驱动的 BC、PPO、CTDE 流水线。
- 实验前拒绝种子泄漏。
- 只有置信度、产量和安全门槛都通过才晋级。
- 失败鲁棒性结果保存在结构化审计注册表。
- 模拟器和规则基线没有第三方依赖。

```bash
python3 main.py play --port 8080
```

学习策略需创建 `.venv-ml`、安装 `requirements-ml.txt` 并运行 M8 流水线。Arena 加载前
会校验注册权重摘要。

## 声明边界

v1.0 证明端到端实验工作流和诚实晋级流程可运行；M8 相对局部行为克隆改善并消除了资源
争用无效动作。它不声称学习策略普遍鲁棒：M10、M11 在恶劣天气和低能量下发现严重存活
下降，候选被拒绝并记录。内置服务器面向本地实验，不提供认证、多用户隔离或生产 SLA。

验证命令为 `main.py --version`、单元测试和 30 回合 Greedy/Assignment 基准。生成的
`runs/`、`models/`、`data/` 目录不进入 Git。
