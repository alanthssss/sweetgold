# SweetGold v1.0.1

[English](v1.0.1.md) | [简体中文](v1.0.1.zh-CN.md)

v1.0.1 是首个明确附带开源许可证的版本。源码、配置、网页 UI 和文档使用 Apache 2.0。

## 改动

- 增加官方 Apache License 2.0 全文。
- 增加包含 `Copyright 2026 alanthssss` 的 `NOTICE`。
- README 说明许可证。
- 明确单独分发的检查点和数据集可能有独立条款。

## 兼容性

该补丁不改变 SweetGold 行为、实验结果、晋级决定或文件格式。它仍是同一个 v1.0 产品与
研究平台，只是明确了复用、修改与分发条款。

## 验证

```bash
python3 main.py --version
python3 -m unittest discover -s tests -v
```

许可证文本发布前与 Apache Software Foundation 官方版本核对。

## 升级说明

v1.0.0 用户在再分发或二次开发时应升级到 v1.0.1，以便许可证和署名随源码归档一起传播。
