我构建 SweetGold，是为了让多智能体强化学习的改善声明更难被“调出来”。策略使用配对
种子，训练与评测范围相互隔离，失败的鲁棒性审计保持公开，晋级权重必须通过完整性校验。
最新策略在六种未使用过的环境分布中达到 100% 蜜蜂存活率和 0% 无效动作率。
项目使用 Apache-2.0，规则型 Arena 只需 Python 即可运行。
