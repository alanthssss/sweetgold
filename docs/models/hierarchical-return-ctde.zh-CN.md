# 分层返航 CTDE 模型卡 / Hierarchical return CTDE

[English](hierarchical-return-ctde.md) | [简体中文](hierarchical-return-ctde.zh-CN.md)

## 身份

- 注册表 ID：`hierarchical-return-ctde`
- 里程碑：M14
- 架构：已接受的 M8 协调式 CTDE 行动者，上层增加确定性的返航、存蜜和充能监督器
- 共享权重：`coordinated-ctde.pt`
- 控制参数：安全余量 6，充能比例 0.8
- 许可证：Apache-2.0

## 预期用途

这是 SweetGold 第一个通过跨分布审计的策略，用于配对种子研究、Arena 比较和工作流演示。
单独权重不是完整策略；复现还需要有版本的分层控制器和注册参数。

## 评测

四种监督器配置只在全新验证种子上比较。选中配置随后在六种场景、每种 50 个全新最终种子
上评测一次：所有场景均达到 100% 蜜蜂存活和 0% 无效动作；蜂蜜中位数为 Assignment
的 148.47%，最差的稀缺花蜜场景也达到 101.16%；恶劣天气蜂蜜为 141.46，对照为 99.48。

## 设计

低层行动者继续选择局部动作并使用分散式采集预约。货物满载、能量接近预计返航预算或季节
临近结束时，高层监督器进入返航模式，把蜜蜂带回蜂巢、存蜜、充能，再把控制权交还学习策略。

## 限制

结论只覆盖六种已声明的模拟器分布，不代表真实机器人或未知环境机制。高层监督器是确定性
人工设计结构；结果证明混合结构的价值，不代表整个层级都由学习产生。

## 来源

行动者权重与 Apache-2.0 的 M8 文件逐字节相同。M14 的新行为来自有版本的控制器代码和
注册参数；验证与最终种子记录在本地运行包和已提交审计中。
